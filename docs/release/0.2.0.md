# gisknife 0.2.0 发布说明

本版本在 `0.1.0` 首发基线之上整合了完整可仿真路网（Roadnet）全链路能力，并在保持 PyPI Python 重算引擎（`gisknife-engine==0.1.0`）与未改动前端/协议子包版本稳定的前提下，对发生代码变更的 4 个 npm 包统一升版至 `0.2.0`。

## 一、核心变更摘要

- **接入 `@gisknife/roadnet@0.1.0` 共享路网引擎**
  - 新增 `gisknife roadnet fetch|build|validate|batch|export` CLI 子命令组，支持 OSM 可行驶路网提取、`highway=traffic_signals` 信号灯与 `type=restriction` 禁转/强制转向关系解析、拓扑/配时检查及 SUMO plain XML / GeoJSON 无头导出。
- **MCP 路网工具扩展（`@gisknife/mcp@0.2.0`）**
  - 新增 6 个 `gis_roadnet_*` MCP 工具，与现有 9 个 GIS 核心工具共存，支持通过 stdio MCP 在本地目录构建、校验与导出路网。
- **WebMCP 工具目录扩充（`@gisknife/webmcp-bridge@0.2.0`）**
  - 扩充至 29 个 WebMCP 工具描述符（新增 6 个页面级路网工具：`roadnet_fetch_osm`、`roadnet_filter_links`、`roadnet_batch_edit`、`roadnet_fillet`、`roadnet_validate`、`roadnet_export`），对齐在线工作台 [gis.taoliapp.com/tools/roadnet](https://gis.taoliapp.com/en/tools/roadnet)。
- **核心取数链路加固（`@gisknife/core@0.2.0`）**
  - Overpass 多镜像回退池新增 `https://overpass.private.coffee/api/interpreter`，并更新 User-Agent 为 `gisknife/0.2.0`。
- **离线发包冒烟门禁强化**
  - 更新 `scripts/smoke-package.sh`，新增 `gisknife roadnet build`（含信号灯与转向限制样本）及 `roadnet validate` 离线安装回归校验。

## 三、发包步骤（在已登录 npm 的机器执行）

> **注意**：`@gisknife/mcp` 与 `gisknife` 在源码中通过 `"workspace:*"` 引用同仓包，**禁止**直接在源码目录运行裸 `npm publish`。请使用 `pnpm publish`（会自动把 `workspace:*` 改写为对应版本号 `0.2.0` / `0.1.0`），或使用下方的 tarball 安全发布方式。

### 方式一：按依赖顺序直接用 `pnpm publish`

```bash
git pull origin master && git checkout v0.2.0
pnpm install --frozen-lockfile && pnpm build

# 1. 先发底层被依赖包
pnpm --filter @gisknife/core publish --no-git-checks --registry=https://registry.npmjs.org
pnpm --filter @gisknife/webmcp-bridge publish --no-git-checks --registry=https://registry.npmjs.org

# 2. 再发上层聚合包
pnpm --filter @gisknife/mcp publish --no-git-checks --registry=https://registry.npmjs.org
pnpm --filter gisknife publish --no-git-checks --registry=https://registry.npmjs.org
```

### 方式二：先 `pnpm pack` 再 `npm publish *.tgz`（规避 pnpm 交互式 2FA/Token 404 问题）

```bash
CAND=$(mktemp -d)
pnpm --filter @gisknife/core pack --pack-destination "$CAND"
pnpm --filter @gisknife/webmcp-bridge pack --pack-destination "$CAND"
pnpm --filter @gisknife/mcp pack --pack-destination "$CAND"
pnpm --filter gisknife pack --pack-destination "$CAND"

npm publish "$CAND"/gisknife-core-0.2.0.tgz --access public --registry=https://registry.npmjs.org
npm publish "$CAND"/gisknife-webmcp-bridge-0.2.0.tgz --access public --registry=https://registry.npmjs.org
npm publish "$CAND"/gisknife-mcp-0.2.0.tgz --access public --registry=https://registry.npmjs.org
npm publish "$CAND"/gisknife-0.2.0.tgz --registry=https://registry.npmjs.org
rm -rf "$CAND"
```
